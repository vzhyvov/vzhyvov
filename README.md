## What I'm building

**[cohortum.ai](https://cohortum.ai)** — turns raw event logs into complete user journeys: the real paths people take through your product, where they get stuck, and the insights already surfaced for you.

**[effectsize.io](https://effectsize.io)** — a library of applied case studies from engineering blogs and conference talks (A/B testing, causal inference, recommendations, search, fraud, LLMs in analytics). Each case is a short digest: the problem, the method, how to apply it and the pitfalls, with a link to the original.

Ask your AI agent instead of searching by hand:

```bash
claude mcp add --transport http --scope user effectsize https://mcp.effectsize.io/mcp
```

Works with Claude, ChatGPT and Cursor — [setup](https://effectsize.io/mcp/).
